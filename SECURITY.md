# Security policy

allowd hasn't been released yet, and isn't meant to be used on real systems. Until its first
release, please report security issues as regular [GitHub issues], and we'll discuss them in the
open.

Once allowd is released, we'll move to a private process for reporting vulnerabilities, which this
document will describe.

[GitHub issues]: https://github.com/trifectatechfoundation/allowd/issues/new
